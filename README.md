# Xem Kênh TV (Android 7+)

App xem kênh truyền hình (nguồn vtvgo.vn, danh sách ở `app/src/main/assets/channels.json`).

## Có file APK
1. Đẩy toàn bộ thư mục này lên repo GitHub (giữ `.github/workflows/build.yml`).
2. Tab **Actions** → chờ "Build APK" chạy xong → **Artifacts** → tải `TVXemKenh-apk`, giải nén lấy `.apk`.
3. Cài APK lên điện thoại Android 7.0 trở lên.
